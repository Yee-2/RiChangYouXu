# 隐私政策（上线前待完善草稿）

版本：草稿 0.1.0。此文档是产品实现说明草稿，不构成法律意见。上线前须由运营者按实际部署、司法辖区和供应商配置核实并完善。

## 本机生活数据

生活清单、出门检查、表具读数、宠物档案和事件保存在当前浏览器 IndexedDB，不会自动上传到社区后端。用户可导出 JSON 文件、导入恢复或清除这些本机记录。设备备份文件由用户自行保管。

## 社区数据

启用社区后，邮箱地址由 Supabase Auth 用于注册、验证、登录和密码恢复；公开资料、动态、图片路径、评论、点赞、话题、关注和举报记录保存在项目配置的 Supabase 数据库与对象存储。动态和图片对社区用户可见，内容隐藏后不再通过应用提供访问签名链接。

## 管理与安全

管理员可在处理举报和违规内容所需范围内查看账号资料与社区内容。账号处理会记录管理员、操作对象、动作、原因和时间。服务端鉴权和数据库 RLS 用于限制访问；没有系统可以承诺绝对安全。

## 账号注销

社区账号注销会删除线上账号、动态、评论、互动关系和社区图片。本机生活数据不会随之删除，用户可自行清理或备份。

## 第三方服务和保留

社区依赖用户自行配置的 Supabase 项目；服务商可能按其政策在指定地区处理和保留数据。运营者必须在此补充实际服务商、区域、日志、邮件发送服务、保留期限和联系渠道。

## 用户权利与联系

上线前补充访问、更正、删除、投诉与隐私请求方式，以及负责处理请求的运营主体和邮箱。
