# 用户协议（上线前待完善草稿）

版本：草稿 0.1.0。公开上线前由实际运营者审核、补充主体信息、服务条款和适用法律要求。

1. 用户应使用本人有权控制的邮箱注册，并保护账号凭据。
2. 用户仅可发布合法且有权使用的内容；不得侵犯他人隐私、著作权或其他权利。
3. 用户上传社区图片即表示其有权上传并展示该图片；用户应避免上传敏感个人信息。
4. 运营者可根据社区规范处理举报、隐藏或移除违规内容、限制违规账号，并记录处理原因。
5. 本机生活记录由用户设备保存；清除浏览器数据可能导致记录丢失。用户应自行导出备份。
6. 账号注销会删除线上社区资料及内容，本机数据需用户在设备上另行清除。
7. 社区服务依赖第三方托管服务的可用性和免费额度；上线前应公布实际服务商与服务变更方式。
8. 在此补充运营主体、联系方式、服务可用性、争议处理、适用法律和协议更新通知方式。
