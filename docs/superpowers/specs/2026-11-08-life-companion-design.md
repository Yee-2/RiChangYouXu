# 日常有序 App 产品与技术设计

日期：2026-11-08  
状态：已由用户确认

## 1. 产品目标

打造一个面向个人的手机优先 H5/PWA，把日常计划、出门检查、家庭抄表、宠物照护与兴趣社区放在同一产品中。个人管理数据默认保存在当前设备，支持文件备份；社区数据需要登录并在线保存。产品以免费试用和小规模运营为起点，避免引入收费 API、短信服务和必需的自定义域名。

## 2. 目标用户和平台

- 面向希望整理个人生活事务、照顾宠物并阅读或发布生活动态的个人用户。
- 第一版为手机优先的响应式 H5/PWA，可通过浏览器访问并添加到主屏幕。
- 社区能力需联网；个人清单、抄表、宠物资料和历史记录可离线使用。
- 第一版不做 Android/iOS 原生应用、家庭共享和云端个人数据同步。

## 3. 产品信息架构

底部导航包含五个入口：**首页、清单、记录、社区、我的**。

- 首页聚合今日待办、出门检查快捷入口、近期抄表和宠物照护事项。
- 清单包含生活办事清单和出门检查模板及一次性检查进度。
- 记录包含水、电、燃气表具与读数，以及宠物档案和日常事件。
- 社区包含动态流、发布、话题页、评论、点赞、个人主页和关注。
- 我的包含账户资料、主题、提醒、本机备份恢复、举报与社区设置。
- 管理后台是单独的受权限保护的网页入口，不在普通用户导航中展示。

## 4. 功能范围

### 4.1 生活办事清单

- 创建、编辑、归档和删除清单。
- 在清单内创建事项，设置标题、可选截止日期、备注和完成状态。
- 可由示例清单复制生成新清单；示例覆盖旅行、搬家等常见场景。
- 首页展示今天及已逾期事项。

### 4.2 出门前检查器

- 用户可创建、编辑、复制和删除自定义模板。
- 创建本次检查时，模板内容复制为一次检查实例；勾选进度单独保存。
- 离开页面或离线后保留进度；完成或用户主动重置后才清空实例勾选。
- 支持默认场景模板，如上班、健身、短途出行。

### 4.3 水电燃气抄表

- 支持新增水、电、燃气表具；记录表具名称、单位、当前读数和日期。
- 每次录入保存原始读数，不覆盖旧记录。
- 按同一表具相邻有效读数计算期间用量；读数下降、日期冲突或非数字值时提示检查，不生成负用量结果。
- 展示历史记录和简单的期间用量趋势；不自动估算费用，不接第三方抄表设备。

### 4.4 宠物日常记录

- 支持建立一只或多只宠物档案：名称、种类、生日（可选）、头像（可选）和备注。
- 记录喂养、体重、疫苗、驱虫、就诊及自定义事件。
- 事件可以设置一次性或重复日期提醒；首页展示临近事项。
- 产品只用于记录和提醒，不生成医疗诊断或治疗建议。

### 4.5 社区

- 邮箱和密码注册、登录、邮箱验证、登出、忘记密码和账号删除。
- 发布文字动态，支持多张图片、表情和 `#话题`；话题可创建或选择已有话题。
- 点击话题进入话题页，按时间查看关联动态。
- 动态支持点赞、评论；评论支持文字、图片和表情。
- 用户可查看公开资料、关注或取消关注其他用户。
- 用户可举报动态、评论或账号，并删除自己的动态和评论。
- 社区图片在线存储；上传限制文件类型、大小和数量，失败时保留草稿文字并允许重试。
- 未登录用户可浏览公开内容；登录后才可发布、评论、点赞、关注和举报。

### 4.6 管理后台

- 后台账号由管理员预先赋予管理员角色，不允许公开注册管理员。
- 管理员通过服务端角色校验访问后台，界面隐藏不能替代服务端鉴权。
- 管理员可检索账号、查看账号状态，暂停、恢复或封禁账号。
- 管理员可检索动态和评论，查看举报队列，隐藏或删除违规内容。
- 每次审核操作记录管理员、目标、动作、原因和时间；操作前要求确认并填写原因。
- 第一版不包括自动内容识别、多级审批或申诉工作流。

### 4.7 本机数据和备份

- 清单、检查模板及实例、表具和读数、宠物档案及事件使用浏览器 IndexedDB 保存。
- 导出单个版本化 JSON 文件，包含全部本机个人管理数据；默认不包含社区账号凭据和线上帖子。
- 导入先校验版本和字段；提供预览，并明确采用“合并”或“替换”策略。第一版默认合并，遇到相同本机 ID 时以导入文件覆盖对应记录，其他记录保留。
- 导入失败不更改数据库；导入成功后提示数量和结果。
- 清除本机数据前需二次确认，并提醒备份不可替代云端同步。

## 5. UI 设计规范

- 风格：年轻、温暖、轻松、有识别度；暖奶油色背景、珊瑚橘作为主要强调色，圆角卡片和清晰留白。
- 图标：采用免费 Material Symbols Rounded 填充风格。底部图标分别为 `home`、`checklist`、`monitoring`、`forum`、`person`；图标统一尺寸和圆角风格，可用柔和彩色图标底区分模块。
- 主题：支持日间和夜间主题；用户手动选择优先，首次访问跟随系统设置。夜间使用炭灰背景和降低亮度的暖色强调。
- 移动端底部导航始终可见；桌面端可转换为侧边导航。
- 所有交互提供加载、空数据、离线、失败和成功状态；键盘焦点、图标按钮可访问名称和足够的触控区域必须保留。
- 首页只突出当日优先事项，不将社区动态挤占个人待办信息层级。

## 6. 技术边界与数据流

- H5/PWA 前端采用 TypeScript 组件化实现；本地数据通过独立数据访问层读写 IndexedDB。
- 社区后端提供邮箱鉴权、关系型数据 API、图片对象存储及数据库行级权限策略。
- 普通用户数据和管理员操作均在服务端检查身份和权限；客户端不得持有服务角色密钥。
- 管理后台作为同一前端工程内的独立路由区域，使用单独的管理员守卫，并复用社区数据 API。
- 前端静态资源部署到免费静态托管；数据库/鉴权/图片使用有免费额度的托管服务。免费服务可能有配额、暂停、备份或地域限制，超额时不保证零费用；生产部署前需要关闭超额计费或设置预算提醒，并披露服务实际成本边界。
- 个人数据默认不上传。社区帖子和互动在线可见；上传前提醒图片会提交到服务端。账号删除流程需定义线上内容处置：默认删除个人身份资料并将帖子标记为已注销用户，给出彻底删除本人内容的选择。

## 7. 错误与边界处理

- 本地存储不可用或空间不足：阻止静默丢失，提示导出备份并给出重试。
- PWA 离线：允许本地模块继续读写；社区显示离线提示并禁用在线操作，避免伪成功。
- 社区请求失败：保留尚未提交的编辑内容；重试操作应避免重复创建帖子、评论或点赞。
- 未验证邮箱：可浏览；禁止社区写操作，并提供重发验证邮件入口。
- 账号封禁：阻止所有写操作并显示原因与申诉联系方式（第一版通过管理员支持邮箱处理）。
- 管理员越权请求：服务端拒绝并记录安全事件；普通用户不能通过修改前端状态访问后台数据。
- 图片加载失败：显示占位和重试入口；删除帖子后清理其关联图片。
- 无效备份或重复数据：展示可读错误，不触碰现有本机数据。

## 8. 分期交付

1. **本地生活模块**：响应式 H5/PWA、日夜主题、首页、清单、检查器、抄表、宠物记录、本机备份恢复。
2. **社区 MVP**：邮箱鉴权、个人资料、图文动态、话题、评论、点赞、关注和举报。
3. **管理后台**：管理员角色、账号处理、内容审核、举报队列和审计记录。
4. **上线准备**：隐私政策和用户协议页面、社区规则、删除账号流程、部署配置、接口文档和产品说明书。

分期顺序优先交付本地价值；社区与后台在后续阶段接入。后台必须与社区写操作同批上线，不能先开放发布再补审核入口。

## 9. 交付文档

代码完成时同时交付：

- `docs/api.md`：鉴权、社区、上传、话题、关注、举报、管理接口的路径、请求/响应、权限、错误码和调用示例。
- `docs/product-guide.md`：用户功能、安装 PWA、四个本地模块、社区使用、日夜主题、备份恢复、账号和管理员操作说明。
- 隐私政策、用户协议及社区规范草稿，并标明需要运营者补齐的联系信息和服务商信息。

## 10. 验收要点

- 无账号、离线状态下可完成四个个人管理模块的基本操作；刷新或关闭页面后数据仍在。
- 导出后可在空白状态导入恢复，非法备份不会改变现有数据。
- 日间/夜间主题可切换并记住选择；移动端导航清晰，适配常见窄屏。
- 邮箱注册验证通过后可发布动态、添加话题、上传图片、评论、点赞及关注；未验证用户不能执行写操作。
- 举报进入管理队列；管理员可按原因处理内容或账号，操作留有审计记录。
- 普通用户不能访问管理员数据或触发管理员操作；服务端权限策略覆盖所有管理 API。
- 上传失败、离线、服务端错误和封禁场景均有可理解提示，不显示虚假成功。
- API 文档和产品说明书与最终实现的接口和页面保持一致。
